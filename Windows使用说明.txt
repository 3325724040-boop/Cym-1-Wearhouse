义乌市艾霓工艺品有限公司 · 商品与库存管理

首次运行
1. 先解压整个 ZIP，不能直接在压缩包中双击文件。
2. 从 https://www.python.org/downloads/windows/ 安装 Python 3.10 或更高版本。
   安装时勾选 Add python.exe to PATH。
3. 打开解压后的项目文件夹，双击 start-windows.bat。
4. 浏览器自动打开库存管理后台和商品展示站两个标签页。
5. 保持黑色运行窗口开启；关闭窗口或按 Ctrl+C 后，网页服务停止。

录入第一款商品
在库存后台点击“新增款式”。填写名称、唯一编号、材质、新旧款、售价、成本和初始数量。
如需客户在展示站看到这款商品，将“独立站展示”设为“上架展示”，保存后刷新展示站。
有图片时填写可公开访问的 HTTPS 图片地址；未填写时显示占位。
修改库存时点击“出入库”，填写数量和原因。不要将售价与成本价混淆。

两个页面的区别
库存后台：你自己录入资料、查看成本、记录出入库。
商品展示站：顾客看到的商品页面，展示上架商品及电话、邮箱。
当前启动方式仅供这台电脑本地使用，没有公网地址；尚未完成独立站公网部署。
不要直接双击 static 文件夹内的 HTML，也不要使用 ChatGPT 内部预览录入库存。

数据保存
数据自动保存到项目文件夹中的 data/warehouse.sqlite3。
下次仍使用同一个文件夹启动即可继续使用。关闭应用后可复制整个 data 文件夹备份。
不要删除 data 文件夹。GitHub 代码和 CSV 不能代替完整数据库备份。
原始 Excel 是空白表；当前尚未提供 Excel 导入功能，产品需在后台录入。

常见问题
- 提示缺少 Python：安装 Python 后重新运行脚本。
- 提示端口占用：检查是否已经开着运行窗口，先关闭旧实例；不要重复双击启动。
- 浏览器未自动打开：启动窗口会显示库存后台和商品站的本机地址，可复制到浏览器地址栏。
- 页面打不开：确认运行窗口仍开启，并查看窗口中的错误信息。
- 展示站没有商品：确认后台已录入且选择“上架展示”，然后刷新展示站。
