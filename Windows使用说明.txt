义乌市艾霓工艺品有限公司 · 饰品库存管理

首次运行
1. 先解压整个 ZIP，不能直接在压缩包中双击文件。
2. 从 https://www.python.org/downloads/windows/ 安装 Python 3.10 或更高版本。安装时勾选 Add python.exe to PATH。
3. 打开解压后的项目文件夹，双击 start-windows.bat。
4. 浏览器会打开本机库存管理后台。
5. 保持黑色运行窗口开启；关闭窗口或按 Ctrl+C 后，后台服务停止。

录入商品
在库存后台点击“新增款式”，填写名称、唯一编号、材质、新旧款、售价、成本和初始库存。
如需保存商品照片，点击“商品图片（从电脑选择）”，可一次选择多张 JPG、PNG 或 WebP 图片（每张不超过 5 MB，每款最多 9 张）。调整后点击“保存款式”。
修改库存时点击“出入库”，填写数量和原因。不要将售价与成本价混淆。

数据保存
数据保存在项目文件夹中的 data/warehouse.sqlite3。关闭应用后可复制整个 data 文件夹备份。
不要删除 data 文件夹。GitHub 代码和 CSV 不能代替完整数据库备份。
图片保存在 data/images 文件夹；备份或迁移时一并保留。
原始 饰品价目表.xlsx 的三个工作表为空；当前尚未提供 Excel 导入功能，商品需在后台录入。

常见问题
- 提示缺少 Python：安装 Python 后重新运行脚本。
- 提示端口占用：检查是否已开着运行窗口，先关闭旧实例；不要重复双击启动。
- 浏览器未自动打开：启动窗口会显示库存后台本机地址，可复制到浏览器地址栏。
- 页面打不开：确认运行窗口仍开启，并查看窗口中的错误信息。

图片管理
- 每款最多 9 张图片；可设主图、前移、后移和移除。
- 可调整裁剪、旋转、亮度、对比度、饱和度、导出尺寸及 JPEG 清晰度。
- 调整后点击“应用调整”，再点击“保存款式”；仅关闭参数窗口不会保存。
- 处理后的图片另存为 JPEG，透明背景变白，原文件保留。

更新程序（保留已录入商品）
1. 关闭黑色运行窗口，先把整个 data 文件夹复制到其他位置备份。
2. 从 GitHub 下载新版 ZIP 并解压。
3. 把新版项目文件和 static、tests 文件夹复制到原项目文件夹，替换同名文件。
4. 保留原项目的 data 文件夹，不能删除。
5. 重新运行 start-windows.bat。
6. 若旧版本中还留有独立站文件，可删除 storefront.py、static/shop.html、static/shop.js、static/shop.css 和 tests/test_storefront.py。

一键更新
1. 首次只需把 update-windows.bat 放入项目文件夹，与 start-windows.bat 放在一起。
2. 关闭运行窗口，双击 update-windows.bat。
3. 更新器会下载新版、自检，备份库存和图片，再替换代码；旧版独立站程序文件会被清除。
4. 若提示端口占用，先关闭旧窗口再试。备份在项目旁的“原文件夹名-backups”文件夹中，不要随意删除。
5. 如果显示恢复或备份失败，保留窗口和文件夹，不要删除 data。
6. 更新器不会自动替换自定义数据库路径中的数据。Windows 更新流程尚未在真实 Windows 电脑验证。
