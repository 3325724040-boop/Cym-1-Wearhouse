# 饰品仓库

中文饰品产品及库存管理应用。Python 3.10+、SQLite，运行时不需要第三方依赖。

## 功能

- 录入、编辑款式名称、唯一款式编号、新款/旧款、材质、销售单价、成本价及备注。
- 新建时填写初始库存；后续通过入库、出库调整数量，保留原因及结余流水。
- 防止负库存，金额按整数分存储；支持并发出库检查。
- 按名称、编号、材质搜索，按新旧款、有库存/零库存筛选。
- 汇总款式数、库存总量、库存成本金额及库存销售金额，导出 UTF-8 CSV。
- 桌面和手机自适应页面。流水时间按浏览器当地时间显示。

## 启动

```bash
cd /workspace/Cym-1-Wearhouse
python app.py
```

默认监听本机 `127.0.0.1:8000`。通过 `HOST`、`PORT` 调整监听位置；通过 `WAREHOUSE_DB` 指定数据库文件路径。
首次启动自动创建 `data/warehouse.sqlite3`，重启保留数据；该目录不提交到 Git。原始 `饰品价目表.xlsx` 保持不变，其三个工作表目前为空。

此版本面向本地、受信任环境，尚未提供登录、角色权限或公网部署配置。云环境内启动不等于已发布为可外部访问的网站。

## 独立站：展示商品，联系店主下单

在另一个终端启动只读商品展示站：

```bash
cd /workspace/Cym-1-Wearhouse
python storefront.py
```

默认监听 `127.0.0.1:8001`，支持 `SHOP_HOST`、`SHOP_PORT`。与管理后台使用相同的 `WAREHOUSE_DB`（默认数据库），无需同时运行后台进程即可浏览已有商品。

- 后台新增或编辑款式，填写客户可见的商品介绍，选择电脑上的商品图片（或填写 HTTPS 图片直链），选择“上架展示”后保存。
- 新建商品默认不上架；前台只展示上架商品，库存只显示“有现货 / 暂时缺货”，不公开具体数量、成本价、内部备注或流水。
- 商品展示站支持款式搜索、新品/经典款筛选、商品详情、联系店主入口；没有在线支付或自动订单系统，客户联系店主后人工确认订单，再由后台记录出库。
- `SHOP_NAME` 配置店铺名称，默认“饰物集”；`SHOP_CONTACT` 配置可公开的微信、电话或邮箱。未配置时明确提示尚未公开联系方式，不显示虚构信息。
- 每款商品最多 9 张图片，可多选 JPG、PNG、WebP 文件，单张最大 5 MB。支持设为主图、前移、后移和移除。第一张作为列表主图，详情页提供缩略图、上一张/下一张和键盘左右切换。
- 点击图片下的“调整参数”，可调整裁剪比例、裁剪放大及水平/垂直位置、90°旋转、亮度、对比度、饱和度、导出尺寸与 JPEG 清晰度。浏览器本地 Canvas 实时预览，不需要安装图片处理依赖。
- 点击“应用调整”后还需“保存款式”才上传并关联。处理图另存为 JPEG，透明背景变白，不放大原像素。已保存文件不覆盖、不自动删除。参数重置作用于本次编辑的来源图，重新打开已保存商品时以当前已保存图片为来源，不提供历史版本恢复。
- 也可添加有权展示的 HTTPS 图片直链，但受外链跨域限制，外链图片需先下载到电脑并重新上传后才能调整。1688 商品页和 file:/// 本地路径不能当作图片直链。
- 启动会自动将旧版单图迁移为画廊第一张，保留库存与流水。建议升级前先停服备份整个 `data`。
- 上传图片保存在数据库旁的 `images/` 目录（默认 `data/images/`），不会提交到 Git。后台可预览上传图片，展示站只提供已上架商品关联的图片，且不接受上传。删除或更换商品图片不会自动清理旧文件，以免影响其他共用图片的商品。
- 公网部署时仅将展示站放在 HTTPS 域名后；后台应保持内网访问，不要将后台端口或接口转发至展示站。当前未配置域名或部署，也未实现后台登录。

## 数据备份

数据库是业务数据，需要独立备份。可在应用运行时使用 SQLite 备份接口创建一致性副本：

```bash
python - <<'PY'
import sqlite3
from datetime import datetime, timezone
from pathlib import Path
Path('data/backups').mkdir(exist_ok=True)
target = 'data/backups/warehouse-' + datetime.now(timezone.utc).strftime('%Y%m%dT%H%M%S%fZ') + '.sqlite3'
with sqlite3.connect('data/warehouse.sqlite3') as source, sqlite3.connect(target) as dest:
    source.backup(dest)
print(target)
PY
```

恢复前停止应用，并保留当前数据库的备份。CSV 方便查看库存，但不包含完整流水和图片，不能代替备份。上传图片独立保存在 `data/images/`；完整备份或迁移请同时保存该目录。最简单的方式是停止程序后备份整个 `data` 文件夹。

## 更新已有 Windows 项目（保留库存）

1. 关闭运行程序的黑色窗口。
2. 将原项目里的整个 `data` 文件夹复制到另一个安全位置备份。
3. 从 GitHub 下载新版 ZIP，解压，把新版项目文件夹里面的全部代码文件和 `static`、`tests` 文件夹复制到原项目文件夹，替换同名文件。
4. 原项目中的 `data` 文件夹必须保留。GitHub 下载包不含 `data`，不要把旧项目删除后直接运行新空文件夹。
5. 在原项目文件夹双击 `start-windows.bat`，然后在浏览器按 Ctrl+F5 刷新。编辑已有款式，选择商品图片，保存后刷新展示站。
